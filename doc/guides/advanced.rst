.. _advanced_guides:

Advanced users
==============

The guides collected here cover features that go beyond the standard
photometric-fitting workflow: they either extend the pipeline with user-provided
code or change defaults that most fits never need to touch. They all assume
familiarity with the :ref:`parameter file <param_file>` and with the
results-analysis workflow.
